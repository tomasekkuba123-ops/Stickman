# Motion library sources
All clips: CMU Graphics Lab Motion Capture Database (http://mocap.cs.cmu.edu) — free to use for any purpose, including commercial (no resale of the raw data as a database).
BVH conversion: cgspeed/Bruce Hahne 2010 release, via github.com/una-dinosauria/cmu-mocap. Retargeted with tools/bvh_retarget.py -> motion_lib.json.
